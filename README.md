# Nutrition API

## Overview

The Nutrition API project is a RESTful web service developed using Java and Spring Boot. It provides detailed nutritional information about various food items, allowing users to search for food items and retrieve essential nutrition facts such as calories, proteins, carbs, and fats. This project aims to help users make informed dietary choices and promote healthier eating habits.

## Features

- **Search Functionality**: Users can search for food items to obtain nutritional information.
- **Nutritional Data**: Retrieve essential nutrition facts, including:
  - Calories
  - Proteins
  - Carbohydrates
  - Fats
- **Database Management**: Utilizes H2 in-memory database for efficient data retrieval and storage.
- **RESTful API Design**: Follows REST principles for seamless interaction with clients.

## Technologies Used

- Java
- Spring Boot
- H2 Database
- Lombok
- Maven
